# ROBLOX 2017

Classic places and icons, with a website for viewing them in 3D:
**https://jogresh7-ship-it.github.io/ROBLOX-2017/**

## Website
- **Places**: explore place files (`.rbxl`) in 3D. The binary format is read by `rbxl.js`.
- **Icons**: classic Roblox icons.
- **Play** (`play.html`): make your own avatar (body colors, hat, face, name) and walk around the baseplate or a place. On PC, use WASD or the arrow keys to move, Space to jump and R to respawn. On phones, use the on-screen joystick and the JUMP button.

To add a place, put it in `Places/` and add it to the `PLACES` list.

## Places
- `Places/Mobile.rbxl`: Mobile place.
