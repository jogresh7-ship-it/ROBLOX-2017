# ROBLOX 2017

Classic Roblox toolbox models, places and icons, with a website for viewing them in 3D:
**https://jogresh7-ship-it.github.io/ROBLOX-2017/**

## Website
- **Toolbox Models**: every model with a 3D preview. Click one to open the interactive viewer, which has a baseplate, a foliage slider, studs and auto-rotate. The viewer reads the original `.rbxm` files directly.
- **Places**: explore place files (`.rbxl`) in 3D. The binary format is read by `rbxl.js`.
- **Icons**: classic Roblox icons.

To add a model, put it in `ToolboxModels/` and add its file name to the `FILES` list in `index.html`. To add a place, put it in `Places/` and add it to the `PLACES` list.

## ToolboxModels
The `ToolboxModels/` folder holds the 2004–05 Roblox toolbox models (.rbxm), from Block 2x4x1 to Red Figure. They were originally collected by Client Search. See `ToolboxModels/README.md` for history and notes. Insert them into an older Studio version (2007–2008) first, because they get corrupted in modern Studio.
